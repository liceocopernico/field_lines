# Installation

* Install UV https://docs.astral.sh/uv/getting-started/installation/
* Inside field_lines folder execute uv sync
* Run program with uv run field_lines.py


# Keyboard shortcuts

* __c__ create positive charge at mouse position
* __m__ create negative charge at mouse position
* __r__ reset charge distribution

# Mouse wheel and buttons

* __wheel_up__ over a charge increase charge value
* __wheel_down__ over a charge decrease charge value
* __left__click__ set x_0 y_0 for the numerical solution of Cauchy problem
